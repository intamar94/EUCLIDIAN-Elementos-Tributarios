# M4 — Cierre de preparación y exportación de informes

## Resultado

Los informes técnicos y para cliente explican ahora qué campos y fuentes faltan antes de compartir el borrador. El checklist siempre conserva cuatro tareas de cotejo y revisión profesional, aunque todos los campos estén completos. No hay inferencia de revisión humana desde metadatos importados.

Los Word descargados identifican fecha de preparación, asunto y tipo de informe en el nombre. Se conservan los estados de borrador y las referencias oficiales; no se envían archivos a destinatarios.

## Corrección de integridad

Un expediente importado podía contener controles prohibidos por XML 1.0 o surrogates aislados: escaparlos como entidades HTML no los vuelve XML válido. El exportador elimina esos caracteres, conserva caracteres Unicode válidos y transforma CRLF, CR y LF en saltos Word reales (`w:br`). Las partes OOXML siguen dentro de un ZIP local sin consultas de red ni relaciones externas nuevas.

Las secciones Word tienen nivel de esquema y mantienen el encabezado junto al siguiente párrafo. La impresión HTML admite dividir secciones largas, evita encabezados sueltos y permite envolver títulos extensos. Completar un informe no acredita que sus fuentes existan, estén vigentes o sustenten conclusiones.
