# EUCLIDIAN — desarrollo local

La interfaz y las funciones se prueban antes de publicar.

## Arranque recomendado

```bash
npx vercel dev
```

Vercel CLI sirve la interfaz y las rutas `/api/*` desde el mismo origen.

## Flujo

1. Editar código.
2. Guardar.
3. Recargar el navegador: `http://localhost:3000`.
4. Probar la bandeja y las rutas API.
5. Ejecutar las pruebas/controles.
6. Solo después publicar.

No introducir datos tributarios reales durante las pruebas locales.
